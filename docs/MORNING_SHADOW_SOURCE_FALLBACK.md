# Morning shadow source fallback

A complete corrected combination can be older than the research freshness
limit while a separate complete raw current-model snapshot has been received.
The morning observer previously stopped at that stale corrected combination.
It now tries its existing raw snapshot path for this case. Fresh corrected
inputs retain priority. Future or malformed corrected timestamps remain blocked.

The raw snapshot keeps its own server receipt, complete city-local hourly
coverage, seven-source identity and separate model family. Its existing
freshness and chronology gates still apply. Missing data remains missing.
No historical packet is reconstructed; no production forecast, source weight,
trial, paper allocation, fee, policy or schedule is changed. Later normal
morning capture and later verified outcomes remain separate acceptance gates.
