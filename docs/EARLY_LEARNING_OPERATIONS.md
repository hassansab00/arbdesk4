# Early learning and candidate registration handoff

## Weather evidence source checkpoint — not deployed

`weather_evidence_review.review` audits retained AWC envelopes against their
own saved publication replies. Its dispute builder preserves original identity
and proposes a superseding `disputed` record with a fresh database receipt;
it does not write to production or recover an original maximum. Passing that
narrow review does not establish full-day completeness. Review live changes
and verify subsequent actual reader/learner runs separately.

The collector's bounded-window proof is retained in the new evidence schema.
It distinguishes successful empty windows from failed, stale, conflicting or
unparseable retrievals, without assuming one report cadence for every airport.
Post-processing reports how many verified facts were accepted as point labels
or excluded for bucket-only/missing truth or mismatched readings. Historical
facts and predictions stay immutable. The shared-weather candidate experiment
and promotion gates remain unchanged.

Private registration completed on 3 Nov. The existing bounded Tick step now
has a registered candidate; capture receipts and prospective scores still
require actual subsequent decisions and settlements. Registration does not
change the production predictor or activate a paper/portfolio strategy.
The operator registration command validates the private artifact before
registration and validates the actual database-reader artifact afterward.
It rejects numeric encoding changes that preserve equality but alter the
fingerprint, mismatched registration receipts and changed cohorts. It never
freezes a historical call or activates a production/paper model.

## Early correction learning evidence — 3 Nov

Early-strength fitting now reports exclusions for original comparison
availability, legacy recipes, incompatible model recipes, morning peak proof,
input/freeze/label chronology, future fits and later duplicates. The counts
travel with each fitted state into the existing validation reports. No new
database reads, schedules, training thresholds, learned weights or serving
rules are introduced. Unknown legacy grids are not reconstructed for learning.

The live saved-comparison replay returns identical eligible rows and fitted
states before and after this diagnostic addition (apart from the new evidence
counts). Controlled tests account for rejected records and verify that legacy
or incompatible comparisons cannot approve an adjustment. Historical calls
remain unchanged. The broader correction review and fitted artifact remain
private; retrospective attribution is not prospective model validation.
