## Read this first

- **Quoted, then real.** The main tables charge the record's price plus the archived books' median half-spread on each side; the last table uses each side's own best ask in the books, on the city-days they cover.
- **Many trades a city-day.** Every side of every bucket whose value beats its cost is a trade, one share each, so trades on one city-day are not independent; the interval resamples whole dates.
- **The rail.** Nothing is bought above 0.97 (P5.9), as on the platform.
